HOW TO VIEW
1. Extract this ZIP file.
2. Open index.html in a web browser.
3. To add a profile photo, click "Upload photo" in the portrait area.

HOW TO PRINT / SAVE AS PDF
1. Open the website.
2. Click "Print / Save PDF".
3. In the print dialog, choose "Save as PDF".

HOW TO EDIT
- Open index.html in a code editor to change text.
- Open style.css to change colors and layout.
- Open script.js to change interactive behavior.

PUBLISH ONLINE
You can upload the files to a static hosting service such as GitHub Pages. Keep all three files in the same folder.
